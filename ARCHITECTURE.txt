C# MESSAGE BROKER / DISTRIBUTED APP FRAMEWORK
=============================================

Runtime flow:
  USER -> Broker UI (Home / Publish / Consume / Acknowledge / Stats)
       -> Broker API -> BrokerService -> BrokerManager
       -> PartitionRouter -> BrokerNode -> InMemoryMessageStore
       -> ReplicationManager -> Response -> Frontend -> USER

Canonical modules:
  shared/        MessageEntry, requests/responses, VersionInfo
  broker/        InMemoryMessageStore, policy, statistics
  distribution/  BrokerNode, PartitionRouter, ReplicationManager, NodeRegistry
  backend_csharp/ API + orchestration + OutboxInboxGuard (compiles broker+distribution)
  frontend_csharp/ Blazor WASM multi-page client (Router + layout; built-in HttpClient)

Conceptual inspiration only (no clone): food-delivery-microservices messaging ideas.
